# Project instructions

## Git snapshots

- After completing one user-requested code task and verifying that it builds or tests successfully, create one local Git commit.
- Use a short, clear Chinese commit message describing the completed task.
- Stage only files related to the current task. Preserve unrelated user changes.
- Do not commit generated files, build outputs, executables, temporary files, passwords, tokens, or other secrets.
- If the build or tests fail, do not create a success commit; explain the failure to the user.
- Do not push commits to a remote repository unless the user explicitly requests it.
